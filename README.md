# KRAFT / ROAST — Specialty Coffee Roastery Website

Адаптивний вебсайт із 3 сторінок для локальної обсмажувальні спешелті-кави **KRAFT / ROAST**.  
Виконаний у вишуканому скандинавсько-японському теплому мінімалізмі на чистому ванільному стеку **HTML5, CSS3 та JavaScript** (без жодних фреймворків, бібліотек чи бандлерів).

---

## ☕ Основні можливості

- **100% Vanilla Stack**: Чистий семантичний HTML5, CSS3 (змінні в `:root`, Flexbox, CSS Grid з `repeat(auto-fit, minmax(...))` та `grid-template-areas`), ванільний ES6+ JS.
- **Повна мобільна адаптивність**: Mobile-first підхід із вивіреними брейкпоінтами (320px–640px, 641px–1024px, >1024px), відсутність горизонтального скролу.
- **Естетика теплого мінімалізму**: Палітра молочно-бежевого фону (`#F9F8F6`), вугільно-чорного тексту (`#1A1A1A`) та приглушеного кавово-теракотового акценту (`#9C5B3E`).
- **Справжній контент спешелті-індустрії**: Q-Grade оцінки (84.5–91.0), конвекційний ростер Loring, мікролоти з Ефіопії, Колумбії, Кенії, Бразилії, Руанди, Панами.
- **Вбудовані фотоматеріали**: Якісні атмосферні фотографії процесу заварювання, цеху обсмаження, кавового посуду та крафтового пакування.

---

## 📄 Структура сторінок

1. **`index.html` (Головна — Бренд & Огляд)**:
   - Хедер з логотипом, десктопною навігацією та анімованим мобільним бургер-меню (з блокуванням скролу `body`).
   - Hero-секція з атмосферою кав'ярні, лотом тижня (Colombia El Paraiso) та ключовими метриками.
   - Секція філософії мікро-обсмаження Loring та прямого імпорту (2-колонковий Flexbox).
   - Секція обраних сортів місяця (CSS Grid з інтерактивними картками та додаванням у кошик).
   - Футер з адресою, годинами роботи та контактами.

2. **`beans.html` (Каталог зерна — Продукти)**:
   - Панель швидких фільтрів на чистому JS («Всі», «Мита обробка», «Натуральна», «Анаеробна», «Під еспресо», «Під фільтр»).
   - Адаптивна CSS Grid сітка з 8 картками мікролотів (дескриптори, висота, спосіб обробки, оцінка SCA, ціна, фото пачки).
   - Жива фільтрація карток без перезавантаження сторінки з анімованим лічильником українською мовою.

3. **`brew-guide.html` (Гайди заварювання & Калькулятор пропорцій)**:
   - Покрокові картки еталонних рецептів: **Hario V60**, **AeroPress**, **Chemex**, **French Press**.
   - **Інтерактивний Brew Ratio Calculator** (побудований на CSS Grid з `grid-template-areas`):
     - Вибір девайса з автоматичною зміною рекомендованого співвідношення (1:16, 1:12, 1:16.6, 1:15).
     - Двосторонній розрахунок: за вагою зерна або за об'ємом води.
     - Сенсорний повзунок-слайдер для швидкого підбору грамажу.
     - Динамічний покроковий графік проливу (Brew Schedule) із розрахунком блумінгу та інтервалів екстракції.

```

```

## 🚀 Запуск проєкту

Проєкт не потребує жодних серверів чи складання (npm, webpack тощо).
Просто відкрийте `index.html` у будь-якому сучасному веб-браузері:

```bash
# Або через подвійний клік на index.html
start index.html
```
